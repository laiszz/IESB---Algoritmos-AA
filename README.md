# Algoritmos - Atividade Ativa

## Dependências

Execute os comandos abaixo, no diretório raiz, para instalar as dependências obrigatórias para o uso do sistema:

`pip install readchar` \
`pip install tabulate`

## Iniciando o Programa

Execute o comando abaixo, no diretório raiz, para iniciar o programa:

`python3 main.py`

## Navegando pelas Opções

Para navegar, clique no número correspondente a uma das opções no Teclado ou NumPad. Não é necessário apertar Enter.
